Paging

Split a logical address into a page number and offset. Use the page table to map that page to a frame; if no frame is mapped, the access causes a page fault.

Address mapping: page number = floor(logical address / page size), offset = logical address mod page size, physical address = frame number × page size + offset.

Page table mapping

Each row maps a virtual page to a physical frame. “Not in memory” means there is no valid frame mapping, so accessing that page causes a page fault.

Segmentation

A logical address is a segment number and an offset. Look up the segment's base and limit; the offset must be smaller than the limit before it can be added to the base.

Address mapping: if offset < limit, physical address = base + offset; otherwise, the address is invalid and causes a segmentation fault.
